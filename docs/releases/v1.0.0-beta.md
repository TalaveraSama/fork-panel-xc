## Fork Panel XC v1.0.0-beta

Primer release del fork de **XC_VM** con panel moderno en **Vue 3 + Vite** y backend **API-first** en PHP 8.3.

### Incluido

- **Frontend Vue 3 + Vite + Pinia + Tailwind** con build de producción verificado (814 módulos):
  dashboard con Chart.js, streams, movies/series, usuarios y líneas, resellers, EPG, bouquets, categorías, ajustes, herramientas, módulos y perfil. Modo oscuro y layout responsive.
- **API propia `ForkPanelXc\`** en `src/Api` con autoloader independiente, así el panel original `XcVm\` sigue intacto:
  router con grupos y middleware, JWT HS256 con refresh, permisos, rate limiting, migraciones SQL.
- **APIs compatibles**: `player_api` (subconjunto Xtream), `panel_api` (MAG/Ministra), tokens HMAC de streaming (`/live`, `/movie`, `/series`, `/epg/{token}.xml`).
- **Sistema de módulos** por manifiesto `module.json` + `ExampleModule` funcional y CLI `module:*`.
- **CLI `console.php`**: `db:migrate`, `db:status`, `module:list|install|enable|disable|uninstall`, `schedule:run|daemon`, `queue:daemon`, `serve`.
- **Despliegue**: `install.py` para Ubuntu/Debian, `docker-compose.yml` (MariaDB 11.4, Redis 7, PHP-FPM, nginx, worker, scheduler), `Makefile`.
- **Todo con licencia AGPL-3.0** y atribución a Vateron Media / XC_VM.

### Verificación de este release

- `php -l` sobre 847 archivos PHP: 0 errores.
- `tests/api-smoke.php`: 19/19 checks (router, JWT, stream tokens, request).
- Prueba real contra MariaDB 11.4: migraciones, login admin, CRUD de categorías/streams, settings, instalación de módulo, bouquets, `player_api/login`, XMLTV y redirección 302 de `/live/{token}`.
- Login y dashboard capturados desde el stack corriendo, sin errores de consola.

### Instalación rápida

```bash
git clone https://github.com/TalaveraSama/fork-panel-xc.git
cd fork-panel-xc
cd frontend && npm install && npm run build && cd ..
sudo python3 install.py
```

O con Docker:

```bash
cp .env.example config/.env
docker compose up -d
docker compose exec php php /home/fork_panel_xc/console.php db:migrate
```

El instalador imprime la contraseña del usuario `admin`. Cámbiala tras el primer acceso.

### Limitaciones conocidas

- 2FA cerrado hasta conectar el puente TOTP del panel original (rechaza códigos en vez de aceptarlos).
- Sin WebSocket en este drop: el dashboard hace polling cada 30 s.
- Facturación/créditos, provisión MAG/Enigma y editor de perfiles de transcoding quedan para la siguiente fase.
