## Fork Panel XC v1.0.0-beta

Primer release del fork de **XC_VM** con panel moderno en **Vue 3 + Vite** y backend **API-first** en PHP 8.3.

### Incluido

- **Frontend Vue 3 + Vite + Pinia + Tailwind** con build de producción verificado:
  dashboard con Chart.js, streams, movies/series, usuarios y líneas, resellers, EPG,
  bouquets, categorías, ajustes, herramientas, módulos y perfil. Modo oscuro y
  layout responsive.
- **API propia `ForkPanelXc\`** en `src/Api` con autoloader independiente, así el
  panel original `XcVm\` sigue intacto: router con grupos y middleware, JWT HS256
  con refresh, permisos, rate limiting y migraciones SQL.
- **APIs compatibles**: `player_api` (subconjunto Xtream), `panel_api`
  (MAG/Ministra), tokens HMAC de streaming (`/live`, `/movie`, `/series`,
  `/epg/{token}.xml`).
- **Sistema de módulos** por manifiesto `module.json`, rutas dinámicas
  (`api_routes`) y CLI `module:*`. Incluye ExampleModule, TMDB y Library Scanner.
- **CLI `console.php`**: `db:migrate`, `db:status`, `module:*`, `user:password`,
  `library:scan`, `schedule:run|daemon`, `queue:daemon`, `serve`.
- **Despliegue**: `install.py` e `install.sh` para Ubuntu/Debian,
  `docker-compose.yml` (MariaDB 11.4, Redis 7, PHP-FPM, nginx, worker,
  scheduler) y `Makefile`.
- **Todo con licencia AGPL-3.0** y atribución a Vateron Media / XC_VM.

### Verificación de este release

- `php -l` sobre 852 archivos PHP: 0 errores.
- `tests/api-smoke.php`: 19/19 checks (router, JWT, stream tokens, request).

### Instalación rápida

Un comando (Ubuntu/Debian):

```bash
curl -fsSL https://raw.githubusercontent.com/TalaveraSama/fork-panel-xc/main/install.sh | sudo bash
```

O desde un clon:

```bash
git clone https://github.com/TalaveraSama/fork-panel-xc.git
cd fork-panel-xc
sudo bash install.sh
```

El instalador de terminal instala nginx/MariaDB/Redis/PHP-FPM, construye el
frontend, crea la base de datos, escribe `config/.env`, configura nginx y los
servicios systemd, aplica las migraciones, crea `media/movies` y `media/series`,
instala los módulos TMDB y Library Scanner e imprime la contraseña de `admin`.

Con HTTPS y TMDB:

```bash
sudo bash install.sh --domain panel.example.com --ssl --tmdb-api-key 'TU_KEY'
```

Alternativa con Docker:

```bash
cp .env.example config/.env
docker compose up -d
docker compose exec php php /home/fork_panel_xc/console.php db:migrate
```

Cambia la contraseña de `admin` tras el primer acceso.

### Correcciones

- El instalador de terminal crea un **pool PHP-FPM propio** que corre como
  `fork_panel_xc`; antes el pool `www-data` no podía leer `config/.env` y el
  login devolvía **500**.
- Menú lateral: botón visible para **expandir** cuando está colapsado (en el
  header, en el borde del sidebar y clicando el logo).
- Modo oscuro/claro: Tailwind usa ahora estrategia `class` (antes `media`), así
  que el botón cambia realmente el tema y no solo el icono.
- Nuevo comando de recuperación:
  `php console.php user:password <usuario> <contraseña>`.
- **Líneas**: ahora se pueden crear, editar, renovar contraseña y borrar desde
  Users & Lines (antes solo existían usuarios). Incluye propietario, fecha de
  expiración, conexiones máximas y rechazo de login para líneas expiradas.
- Guía de diagnóstico: [docs/TROUBLESHOOTING-LOGIN.md](docs/TROUBLESHOOTING-LOGIN.md).
- Los fuentes de los módulos Tmdb y Library ahora están versionados en el repo
  (antes `.gitignore` los excluía).

### Módulo TMDB

- Importa póster, backdrop, sinopsis, año, duración, géneros y valoración desde
  themoviedb.org al crear películas y series.
- Configura la API key en **Settings → Streaming → TMDB** (o en Settings →
  Modules); también con `--tmdb-api-key` al instalar. Respuestas cacheadas 24 h.
- Rutas del módulo cargadas dinámicamente solo mientras está habilitado.
- Guía: [docs/modules/TMDB.md](docs/modules/TMDB.md)

### Detalle de streams (Stats / Settings / Logs)

- La pestaña **Stats** muestra viewers, conexiones totales, bandwidth, estado y
  el último test de fuente con latencia/código HTTP.
- **Settings** permite editar nombre, fuente, icono, tipo, categoría, EPG channel
  ID y enabled sin salir del detalle, con botón de test.
- **Logs** lee la nueva tabla `stream_logs`: creación, cambios y resultados de
  test quedan registrados con nivel y contexto JSON.
- Migración: `005_stream_logs.sql`.

### Compatibilidad Xtream Codes (IPTV Smarters)

- Nuevos endpoints compatibles: `/player_api.php` (login + catálogo + VOD +
  series), `/get.php` (M3U), `/xmltv.php` y
  `/live|movie|series/{username}/{password}/{id}.{ext}`.
- Autenticación con las credenciales de una línea (enabled y no expirada).
- **Gateway de streaming**: el panel descarga/reescribe las playlists HLS y
  proxya los segmentos (`/stream/{token}`), en vez de redirigir al origen.
- Estadísticas reales por sesión: viewers, conexiones, bandwidth, línea
  `connected`/`bitrate` y estado `online/offline` del canal.
- nginx enruta también `*.php` y `/stream/` al front controller del API.
- Guía de configuración: [docs/XTREAM-COMPAT.md](docs/XTREAM-COMPAT.md)

### Library Scanner

- Escanea carpetas locales del VPS y crea películas, series y episodios a partir
  del nombre de archivo (`Matrix.1999.1080p.mkv`, `Show.S01E02.mkv`).
- Escaneo manual (UI o `library:scan`), dry-run, límite por tanda y escaneo
  automático cada N minutos desde el scheduler.
- Registro en `library_files` (skip de archivos sin cambios, marcado `missing`),
  y enriquecimiento opcional con TMDB. Conserva fuentes HTTP manuales.
- El instalador crea `media/movies` y `media/series` e instala el módulo.
- Guía: [docs/modules/LIBRARY.md](docs/modules/LIBRARY.md)

### Limitaciones conocidas

- 2FA cerrado hasta conectar el puente TOTP del panel original (rechaza códigos
  en vez de aceptarlos).
- Sin WebSocket en este drop: el dashboard hace polling cada 30 s.
- Las fuentes locales del Library Scanner se guardan como `file://…`; el endpoint
  de streaming solo redirige HTTP/HTTPS, así que esos títulos quedan catalogados
  pero aún no se sirven por HTTP.
- Facturación/créditos, provisión MAG/Enigma y editor de perfiles de transcoding
  quedan para la siguiente fase.
